# kids-kick ⚽

Ein web-basiertes Fußballspiel im FIFA-Style (à la Nintendo / PlayStation), in dem Kinder- und Jugendmannschaften gegeneinander antreten.

## Fokus (Phase 1)

- **F- und E-Jugend**
- Spielmodus **4+1** (vier Feldspieler + Torwart)
